# 🐾 宠物住院喂药排班台

纯前端单页应用，无任何依赖与构建步骤：直接用浏览器打开 `index.html` 即可。

## 功能

- **预置数据**：6 只住院宠物（柯基、英短、金毛、垂耳兔、苏卡达、布偶）、3 名护理员（王护 / 李护 / 赵护），每只宠物带药物档案，每种药有最小给药间隔与上次给药时间。
- **10 分钟槽排班**：12 小时窗口（72 槽）的甘特图，一行一名护理员。
- **硬约束**
  - 同一名护理员同一槽最多一项任务；
  - 同一种药两次给药不得早于其最小间隔（同时与「上次给药时间」「已锁定急救」「其他已排任务」三方比对）。
- **优先级**
  - 普通：按加入顺序贪心抢占最早合规槽；
  - 高优先级：优先插队，可挤掉普通任务——被挤掉的普通任务会自动重新排到仍满足间隔的槽位；
  - 急救：立即锁定在当前槽，任何人/重排都不能移动它；违反间隔或护理员占用时直接拒绝并说明原因。
- **待排与冲突原因**：窗口内找不到合规槽的任务保持待排，卡片写明原因（间隔未到且超出 12h 窗口 / 被锁定急救封锁 / 合规槽护理员全部占满），并附最近可行槽位明细。待排普通任务可一键升为高优先级重排。
- **时间推进**：每 30 秒自动重排；完整经过的槽视为已给药并回写「上次给药时间」；窗口随时间前滚。
- **本地持久化**：所有数据存 `localStorage`（键 `pet-med-board-v1`），刷新保留；顶栏「恢复预置」可清空重置。

## 排班算法要点

每次重排先固定全部急救任务建立占用表（护理员×槽、同药时间点、护理员负载），
其余任务按「高优先级 → 普通、同级按加入先后」排序，依次贪心选择窗口内最早的合规槽，
并在该槽挑当前最空闲的护理员（表单指定护理员时作为软偏好）。
找不到槽的任务留在待排池，并由诊断函数给出可读的冲突原因。
